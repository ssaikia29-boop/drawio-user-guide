# Frequently Asked Questions

<details>
<summary><strong>Why is a connector not connecting to a shape?</strong></summary>

Drag the connector endpoint until the connection point on the shape is highlighted.

For more information, see [Connect shapes](/docs/creating-diagrams/connect-shapes).

</details>

<details>
<summary><strong>How do I bring an object to the front?</strong></summary>

Select the object, open the **Arrange** menu, and select **To Front**.

For more information, see [Arrange overlapping objects](/docs/editing-diagrams/arrange-objects).

</details>

<details>
<summary><strong>How do I align multiple shapes?</strong></summary>

Select at least two shapes, open the **Arrange** menu, and choose the required alignment option.

For more information, see [Align shapes](/docs/editing-diagrams/align-shapes).

</details>

<details>
<summary><strong>Why is my exported diagram difficult to read?</strong></summary>

Review the export settings before exporting. Adjust the settings to make sure the diagram is clear and readable.

For more information, see [Export a diagram](/docs/managing-diagrams/export-diagram).

</details>
