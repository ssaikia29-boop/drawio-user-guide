# Understanding draw.io editor

The draw.io editor provides several tools and panels that help you create and edit diagrams. Understanding these areas makes it easier to work with the application.

The editor consists of the following main areas:

![The draw.io editor interface](/img/drawio_ui.png)

## Menu bar

The menu bar appears at the top of the editor. It provides access to commands and settings organized under these menus:

- **File:** Create, open, save, and export diagrams.
- **Edit:** Edit and modify diagram objects.
- **View:** Adjust the editor view and display settings.
- **Arrange:** Align, position, and arrange objects.
- **Extras:** Access additional tools and options.
- **Help:** Find help and application information.

## Toolbar

The toolbar provides quick access to commonly used commands, such as:

- Zoom
- Undo
- Redo
- Delete
- Fill Color
- Connection

## Shapes panel

The shapes panel appears on the left side of the editor. It contains different categories of shapes and elements that you can add to your diagram.

Examples include:

- Circles
- Squares
- Rectangles
- Diamonds
- Curves
- Callouts

## Canvas

The canvas is the main workspace where you create and edit diagrams. You can add shapes, enter text, connect objects, and arrange diagram elements on the Canvas.

## Formatting panel

The formatting panel appears on the right side of the editor. It provides options to customize the canvas and selected diagram objects.

You can use this panel to adjust:

- Canvas view
- Grid and page settings
- Shape formatting
- Text formatting
- Object arrangement
