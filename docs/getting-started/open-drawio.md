# Open draw.io

You can access draw.io through a supported web browser. Make sure your computer is connected to the internet before opening the application.

## Procedure

1. Open a supported web browser on your desktop or laptop.
2. Enter the following URL in the address bar: https://app.diagrams.net/ .
3. Press **Enter**.

The draw.io editor opens with a blank canvas. You can now start creating a diagram or select a template.
