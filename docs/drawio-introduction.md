# Introduction

draw.io, also known as diagrams.net, is a diagramming tool that you can use to create, edit, and share diagrams. It is available as a web application, a desktop application, and through integrations with supported platforms.

You can use draw.io to create different types of diagrams, including:

- Business process diagrams
- Flowcharts
- Organization charts
- Architectural diagrams and layouts
- UML diagrams
- Entity-relationship (ER) diagrams
- Database schemas
- Business Process Model and Notation (BPMN) diagrams
- Circuit diagrams

## About this guide

This guide explains how to use draw.io version 32.2.0 in a web browser on a desktop or laptop computer. It covers the essential features and workflows for creating, editing, formatting, saving, and exporting diagrams.

The guide is intended for:

- Business analysts
- Project managers
- IT professionals
- Technical writers
- Students and educators
- Anyone new to diagramming

You do not need prior diagramming experience to follow this guide.

## What you'll learn

By using this guide, you will learn how to:

- Open draw.io and understand its editor.
- Select templates and shapes.
- Add text and connect shapes.
- Move, resize, and format diagram objects.
- Align and arrange objects.
- Save and export diagrams.
