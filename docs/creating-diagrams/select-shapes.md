# Select shapes for a diagram

Shapes are graphical elements that you can add to a diagram to represent objects, processes, or other information. Whether you are working with a template or a blank canvas, you can add shapes to your diagram.

draw.io provides a variety of shapes that you can use to create diagrams. You can find these shapes in categories in the **Shapes** panel on the left side of the editor.

## Procedure

1. Open a diagram in the draw.io editor.
2. In the left panel, if the shape category containing the shape isn't expanded, click the category name. For example: **General**.
3. Click the shape you want to use.
4. Repeat steps 1 and 2 to add more shapes.

The selected shape appears on the canvas.

You can add different shapes depending on the type of diagram you want to create.

## Available shapes

Some commonly used shapes include:

- Squares
- Rectangles
- Circles
- Callouts
- Eight-point stars
- Polylines

You can combine different shapes to create your diagram.
