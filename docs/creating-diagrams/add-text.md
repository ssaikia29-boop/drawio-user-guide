# Add text to shapes and connectors

You can add text to shapes and connectors to describe diagram elements and explain relationships between them.

## Procedure

1. Open a diagram in the draw.io editor.
2. On the canvas, click the shape or connector where you want to add text.
3. Enter the text you want to display.
4. Click outside the selected object to finish editing.

The text appears inside the selected shape or along the connector.

You can use the formatting panel to customize the text's font, size, alignment, and color. To learn more, see [format shapes](../editing-diagrams/format-shapes.md).
