# Arrange overlapping objects

When objects overlap on the canvas, you can change their order to control which object appears in front of or behind another.

## Procedure

1. Click the object you want to reposition.
2. In the menu bar, click **Arrange**.
3. Click the required arrangement option.

## Arrangement options

| Option | Description |
|---|---|
| To Front | Moves the selected object in front of all other objects. |
| To Back | Moves the selected object behind all other objects. |
| Bring Forward | Moves the selected object forward by one level. |
| Send Backward | Moves the selected object backward by one level. |

The object's position in relation to other objects changes according to the option you select.
