# Save a diagram

You can save a diagram at any point while creating it. When you save a diagram, draw.io stores it in the selected location.

You can save a diagram using **Save** or **Save as**. The option you use depends on whether you want to save changes to an existing diagram or save a diagram as a new file.

- **Save:** Use this option to save changes to a diagram that has already been saved. For instructions, see [Save changes to an existing diagram](#save-changes-to-an-existing-diagram).
- **Save as:** Use this option to save a new diagram or save an existing diagram with a different file name or location. For instructions, see [Save a new diagram](#save-a-new-diagram).

When saving a diagram, you can select a supported online storage service or your local computer as the storage location, depending on the options available in your draw.io environment. This section covers saving a file to your local computer.

The XML (`.drawio`) format is selected by default when saving a diagram as a draw.io file. If you want to continue making changes to the diagram, save it in this format.

## Save changes to an existing diagram

1. Open the diagram you want to update.
2. Make the required changes.
3. Select **File > Save** from the Menu bar.

Your changes are saved to the diagram.

## Save a new diagram

1. Open the diagram in the draw.io editor.
2. On the menu bar, select **File > Export as**.
3. Enter a name for the diagram.
4. Select a location to save the file.
5. Click **Save**.

The diagram is saved with the specified name and location.

## File format

draw.io uses XML (`.drawio`) as its default editable file format. You can reopen this file in draw.io to continue editing your diagram.
