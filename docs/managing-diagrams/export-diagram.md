# Export a diagram

You can export a diagram in different formats to share, publish, or embed it in other applications.

Before exporting, make sure your diagram is complete. If you want to retain an editable copy, see [Save a diagram](save-diagram.md).

## Procedure

1. Open the diagram you want to export.
2. On the menu bar, select **File > Export as**.
3. Select the required file format.
4. In the Export dialog box, configure the export settings as needed.
5. Click **Export**.
6. Enter a file name and select a location to save the file.
7. Click **Save** to export the diagram.

The diagram is exported in the selected format.

## Available export formats

- ```PNG```
- ```SVG```
- ```HTML```

>[!Note]
Exported files are generally intended for sharing or publishing. Use the `.drawio` format if you need to continue editing the original diagram.

>[!Tip]
Review the export settings before exporting to make sure the diagram is clear and readable.
